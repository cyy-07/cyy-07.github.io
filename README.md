# cyy-07.github.io

This is my personal website.

[Visit my website](https://cyy-07.github.io/)

The bilingual portfolio is served directly from `index.html` through GitHub Pages.

- `assets/images/photo.jpg` is the profile photo.
- `assets/research/fgnn-toc.png` is the FGNN manuscript ToC.
- `assets/research/moo-fig1.png` is Figure 1, the system architecture from the current furnace scheduling manuscript.
- `assets/research/catalysis-volcano.png` is the supplied catalysis activity surface.
- `assets/projects/data.js` contains the eight bilingual project summaries and detail pages. Screenshots and original coursework figures are stored alongside it. `browser.js` handles category tabs, detail navigation, and shareable project links.
- `reports/energy/` contains the original interactive CS228 report and dataset explorer. `reports/features/report.pdf` and `reports/flight/proposal.pdf` contain the original coursework materials.

Project links use `#projects/hackathons/<slug>` or `#projects/coursework/<slug>`. The undergraduate credit breakdown counts retaken courses once and separates 20 CS/computing credits from 158.5 other degree credits, for 178.5 in total. Mathematics, languages, and general education are included in the degree portion.

Run `python -m http.server 8765` from this directory to preview the site locally.
